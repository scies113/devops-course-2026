# Сравнение работы с Git в IDE (VS Code) и в терминале (CLI)

## 3 преимущества работы с Git в VS Code:
1. Наглядный просмотр разницы (diff) «до/после» рядом в редакторе с подсветкой удалённых и добавленных строк.
2. Удобное расширение GitLens для мгновенного визуального отслеживания автора строки (git blame).
3. Простое и интуитивное разрешение конфликтов слияния кликом по кнопкам выбора изменений.

## 1 преимущество работы через терминал (CLI):
1. Полный контроль и предсказуемость при выполнении сложных операций (interactive rebase, cherry-pick, управление multi-remote), а также гарантированная доступность на удалённых Linux-серверах без графической оболочки.
