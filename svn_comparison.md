# Знакомство с SVN и сравнение с Git

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка представляет собой легковесную ссылку (указатель) размером всего 41 байт на конкретный коммит. Создание ветки происходит мгновенно в оперативной памяти. В SVN ветка — это полное физическое копирование директории проекта на сервере, что требует времени, дискового пространства и сетевых запросов.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет, в SVN сделать коммит без доступа к сети невозможно, поскольку SVN является централизованной системой контроля версий (CVCS) — все коммиты отправляются напрямую в единую базу данных на сервере. В распределённой системе Git (DVCS) каждый разработчик хранит полную копию репозитория у себя, поэтому коммиты выполняются локально в офлайн-режиме.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
1. При работе с огромными монорепозиториями с тяжелыми нетекстовыми ассетами (графика в играх, 3D-модели, видеомонтаж), где не требуется выкачивать всю историю проекта целиком (SVN поддерживает частичный чекаут отдельных подкаталогов).
2. В корпоративных инфраструктурах с жёсткими требованиями безопасности, где необходим гранулярный контроль прав доступа к отдельным директориям репозитория на уровне прав пользователей.
